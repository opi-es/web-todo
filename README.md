# Веб-планировщик задач (Web Todo)

## Описание проекта

**Web Todo** — это минималистичный веб-сервис для управления задачами с поддержкой аутентификации. Проект демонстрирует:

- Работу веб-сервера на Go
- Взаимодействия фронтенда и бэкенда
- Систему аутентификации 
- Хранение данных в SQLite
- Контейнеризации приложения через Docker

**Ключевые возможности**:
✓ Создание, редактирование и удаление задач  
✓ Отметка выполнения задач  
✓ Фильтрация задач по статусу (все/выполненные/активные)  
✓ Защита API паролем (если задан `TODO_PASSWORD`)  
✓ Автоматическое обновление данных без перезагрузки страницы  

**Технологический стек**:
- **Бэкенд**: Go
- **Фронтенд**: HTML/CSS
- **База данных**: SQLite 
- **Инфраструктура**: Docker

## Запуск проекта локально

### Базовый запуск (без Docker)
1. Установите Go 1.23+
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/opi-es/web-todo.git
   cd web-todo
3. Запустите сервер:
    go run ./cmd/ -port=7540
4. Откройте в браузере:
    http://localhost:7540

Расширенные параметры
Флаги командной строки:
-dbfile    # Путь к файлу БД (по умолчанию "scheduler.db")
-port      # Порт сервера (по умолчанию 7540)
-password  # Пароль для аутентификации (опционально)

* Запуск с Docker
1. Соберите образ: 
    docker build -t web-todo .
2. Запустите контейнер:
    docker run -d \
    -p 7540:7540 \
    -v $(pwd)/data:/data \
    --env-file .env \
    --name todo-app \
    web-todo
3. Откройте в браузере:
    http://localhost:7540

**Важные адреса**
Основной интерфейс: http://localhost:7540
Страница входа: http://localhost:7540/login.html

2. Получите токен (в новом терминале):
    curl -X POST http://localhost:7540/login.html \
  -H "Content-Type: application/json" \
  -d '{"pass| jq -r '.token'word":"testpass"}' \
  

3. Команды тестов:
    **Все тесты**
    go test ./tests/ -v

**Важные параметры тестов**
